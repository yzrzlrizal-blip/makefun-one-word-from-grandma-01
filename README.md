Entrants send exactly one word: the word their grandma would text about AI. A judge model compares words two at a time and the funniest, most grandma-like word wins.

## Run it

```sh
python3 main.py
```

## The word

`contraption` — the warm, baffled word a grandma reaches for when a machine
she doesn't quite trust does something clever anyway. `main.py` writes those
eleven bytes (no punctuation, no trailing newline) to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (or `/output` when unset), using only the Python
standard library. Every run produces byte-identical output.
